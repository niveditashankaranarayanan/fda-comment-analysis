Tier 1 — Filename Signal
FDA submission filenames contain submitter-supplied category tokens. Matched by substring against a 17-entry lookup table. Highest-confidence tier — no body text needed.

Tier 2 — Body Phrase Signal
Scans document body for org-identifying phrases in fixed priority order. Priority prevents generic commercial language (Industry) from overriding specific institutional identifiers.
# Priority order (highest → lowest) Society → "american college of cardiology" "on behalf of our members" NonProfit → "501(c)(3)", "patient-led" HealthSystem→ "mayo clinic", "our hospital" Academia → "phd student", "our lab" Individual → "i am writing as a clinician" Industry → "our product", "series e"
Tier 3 — Keyword Frequency Fallback
Scores each type against a domain keyword list; assigns the highest-scoring type. Applied only when Tiers 1–2 produce no match (42 documents, 33.6%). Lowest-confidence tier.
# KEYWORD_FALLBACK scores Society: ["members","society","association","college","professional organization"] NonProfit: ["nonprofit","advocacy organization","patient advocacy","coalition"] HealthSystem: ["hospital system","health system","integrated delivery"] Academia: ["university","professor","phd","faculty"] Individual: ["i am","my practice","personally"] Industry: ["company","manufacturer","product","platform"] # assigned_type = argmax(keyword_count per type)
Theme Scoring — Keyword Frequency (Multi-Label)
Each document receives all themes scoring above zero, ranked by hit count, capped at 5. Raw frequency (not TF-IDF) is used so shorter documents are not penalised for theme detection. 10 themes, each operationalised as a keyword lexicon derived from FDA RFC questions, prior literature, and inductive pilot reading (n=20 stratified documents).
for each theme T: score(T) = Σ occurrences(keyword ∈ T, document_text) assigned = [T for T if score(T) > 0], sorted desc, top-5 # Example: "Performance Drift" lexicon ["drift","temporal","distribution shift","data shift", "population shift","concept drift","model decay", "degradation","stability","longitudinal performance"]
G² Log-Likelihood Keyness
For each submitter type, which terms are significantly overrepresented compared to the rest of the corpus? Computed without any knowledge of the classification lexicons — serves as independent lexicon validation.
G² = 2(a·ln(a/E₁) + b·ln(b/E₂)) min 20% in-group doc frequency overrepresented terms only
Formula
G² = 2 · [ a·ln(a/E₁) + b·ln(b/E₂) ] a = observed frequency in target-type documents b = observed frequency in all other documents E₁ = expected frequency in target group under H₀ E₂ = expected frequency in out-group under H₀ E₁ = N_in · (a+b) / (N_in + N_out) E₂ = N_out · (a+b) / (N_in + N_out) # Significance thresholds G² > 3.84 → p < 0.05 G² > 10.83 → p < 0.001 G² > 15.14 → p < 0.0001 # Filter: term must appear in ≥20% of in-group documents # Direction: only overrepresented terms (a/N_in > b/N_out)

NMF and LDA are different generative models. NMF factorises the TF-IDF matrix; LDA is a probabilistic generative model over word counts. Vocabulary clusters appearing in both — e.g. metrics / drift / automated and regulatory / care / safety — are model-independent corpus structure, not algorithmic artefacts. These converge with the deductively coded themes Metrics & Measurement and Regulatory Framework.

Check 1 — 5-Fold Cross-Validated Naive Bayes sklearn MultinomialNB
A Multinomial Naive Bayes classifier is trained on document text (TF-IDF features) to predict submitter type. Cross-validation accuracy measures whether type labels are predictable from language alone. The classifier has no access to the rule system.
Pipeline([ ('tfidf', TfidfVectorizer(max_features=500, ngram_range=(1,2), min_df=3, sublinear_tf=True)), ('nb', MultinomialNB(alpha=0.5)) ]) cross_val_score(pipe, texts, y, cv=5, scoring='accuracy') Result: 36.0% ± 5.1% Random: 16.7% (1/6 classes) Ratio: 2.2× random baseline
Check 2 — Nearest-Neighbour Cosine Consistency cosine_similarity
For each document, identify its TF-IDF cosine nearest neighbour. Measure the proportion of pairs where both share the same type. Random baseline = Σpᵢ² ≈ 22.1% (accounts for unequal class sizes).
sim = cosine_similarity(X_tfidf) fill_diagonal(sim, 0) for i: nn = argmax(sim[i]) match = (type[i] == type[nn]) consistency = count(matches) / n Result: 70.4% Random: ~22.1% (Σpᵢ² for observed distribution) Ratio: 3.2× random baseline

Methods Paragraph
All 125 public comments submitted to FDA Docket FDA-2025-N-4203 (October–December 2025) were extracted from PDF and DOCX source files using pdfminer.six and python-docx. Submitter classification applied a deductive content analysis framework (Mayring 2000) operationalised as a three-tier priority rule system: (1) filename-embedded submitter labels, (2) organisationally-identifying body phrases scanned in fixed priority order (Society > NonProfit > HealthSystem > Academia > Individual > Industry), and (3) domain keyword frequency scoring as a fallback. Thematic coding applied ten keyword lexicons derived from the FDA's request for comment questions, prior AI medical device literature, and inductive pilot reading of a stratified 20-document sample. Sentiment orientation was coded using a domain-specific regulatory discourse lexicon. Classification validity was assessed through five independent checks: (1) G² log-likelihood keyness (Dunning 1993) confirmed lexicon terms are significantly overrepresented in their target groups; (2) five-fold cross-validated Multinomial Naive Bayes achieved 36.0% accuracy (±5.1%) predicting submitter type from text, 2.2× the 6-class random baseline of 16.7%; (3) nearest-neighbour TF-IDF cosine consistency of 70.4% (3.2× the random baseline of ~22.1%); (4) NMF (k=4, coherence=0.3728) and LDA independently produced topic structures convergent with the deductive codes; (5) optimal topic count k=4 was selected by maximising intra-topic document coherence over k=4–12. All theme frequency estimates carry 95% bootstrap confidence intervals (n=1,000 resamples, random_state=42).
